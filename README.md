# 🤖 Telegram Filter Bot

Bot lọc tin nhắn tự động cho nhóm Telegram với AI cục bộ (không cần API)

## Tính năng
- ✅ Lọc từ cấm thủ công
- 🤖 AI phát hiện nội dung xấu (offline)
- 🌐 Dashboard quản lý trực quan
- 📊 Log lịch sử vi phạm

## Cài đặt

```bash
git clone https://github.com/YOUR_USERNAME/telegram-filter-bot.git
cd telegram-filter-bot
pip install -r requirements.txt
python bot.py
